## 1. Pendahuluan
Proyek UTS ini adalah pembuatan website statis untuk sebuah usaha jasa titip (jastip) barang dari luar negeri bernama yatallgie. Jastip adalah layanan di mana seseorang membelikan barang di luar negeri untuk orang lain lalu mengirimkannya ke Indonesia. Website ini dibuat supaya calon pembeli bisa melihat produk apa saja yang bisa dititipkan, membaca informasi tiap produk, dan mengisi formulir pemesanan tanpa harus bertanya satu per satu lewat pesan pribadi. Tujuan proyek ini adalah menerapkan HTML dan CSS yang sudah dipelajari di kelas ke dalam sebuah website dengan beberapa halaman yang saling terhubung.

## 2. Struktur dan Isi Website
Website Yattallgie terdiri dari 5 file utama, yaitu 3 file HTML, 1 CSS, dan 1 JavaScript.

- **home.html**: Halaman utama yang berisi beranda dan informasi tentang layanan Yattallgie.
- **katalog.html**: Menampilkan katalog produk dari berbagai negara, yaitu Tiongkok (obat dan sepatu), Thailand (baju dan atasan), Korea Selatan (skincare), serta Jepang (snack).
- **pemesanan.html**: Halaman yang berisi informasi mengenai pemesanan produk.
- **style.css**: Mengatur tampilan, warna, dan tata letak website.
- **script.js**: Menambahkan fungsi sederhana menggunakan materi *Introduction*.

Pada bagian header, website memiliki lima menu navigasi, yaitu **Beranda, Tentang, Katalog, Pemesanan, dan Contact Us**. Menu tersebut digunakan untuk memudahkan pengunjung menemukan informasi pada website.


## 3. Proses Pengerjaan
Pengerjaan website dimulai dengan membuat file HTML terlebih dahulu, yaitu halaman Home, kemudian Katalog, dan Pemesanan. Setelah ketiga file HTML selesai, saya melanjutkan dengan membuat file CSS untuk mengatur tampilan website. Tahap terakhir adalah membuat file JavaScript dengan menerapkan materi *Introduction* yang telah dipelajari.

Kendala yang dialami adalah ketika mengunggah website ke GitHub, terutama pada bagian gambar atau foto yang tidak muncul. Untuk mengatasinya, saya memeriksa kembali lokasi penyimpanan gambar, nama file, dan penulisan alamat gambar agar sesuai dengan struktur folder.
